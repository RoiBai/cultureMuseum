# Three.js 三维时间轴验证

2026-10-01，透视镜头与景深版本。

- 147 个器物纹理加载完成，失败 0 个；浏览器没有 WebGL/着色器错误。
- 场景使用 PerspectiveCamera，器物保持世界空间方向，仅悬停或键盘聚焦时转向镜头。深度纹理后处理提供轻度远近虚化，水平 HTML 名称不参与虚化。
- 同代前后错列，每组最多四件；战国 21 组、清代 5 组。没有展台底板。
- 1440 × 960 大屏检查器物排布与文字；偏移到器物旁或上方的标签使用细引线标明对应关系。
- 默认视角约 −49° / 24°；切换“转动视角”并拖动后，角度变为约 −62° / 29°，近远景相对位置和遮挡随之变化。复位恢复默认角度。转动范围限制保证时间向右上延伸。
- 1068 × 744 桌面标签计算字号 16px，430 × 900 窄屏 15px，文字无旋转和缩放；窄屏横向页面溢出为 0。
- 窄屏从史前 01/04 切至 02/04，镜头分别停靠玉飞鹰、玉头人像，名称随物件保持可读。
- 赤红筛选提取 18 件，镜头升至上层，底层保留；“俯看全谱”可返回下层。
- 在上层聚焦彩绘凤纹竹筒后，器物朝向镜头，旁侧信息保持显示；Enter 打开同名详情。标签不会因逐帧显示更新而丢失键盘焦点。
- `npm run check` 覆盖数据/二维布局、70 个三维特征分组、唯一性、时序、布局槽位、透视方向、转动范围和逐组可达性。同等世界尺寸物件在测试前后位置的投影大小比为 1.37。
- 系统减少动态效果设置由代码支持；未修改用户系统设置。
