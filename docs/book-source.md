PDF 第 1 页为封面，第 2 页空白，第 3–6 页为目录，PDF 第 7–301 页对应正文页 1–295。逐页记录见 `dist/data/book-index.json` 的 `coverage.pages`；图片与图内标注另作视觉核对。源 PDF 和完整逐页文本不随网站发布。

## 引用与身份

- 文字引文只去除版面换行及多余空白，保留书中用字、标点与原有错误。跨页原段保留每页片段与双页码；图内转录和参考文献条目另作标示。
- 网页默认呈现每个主题／对象的一段综合讲解，明确标示“依据原书整理”，不伪装成逐字引文；显示所用依据的书内页码，不打开 PDF。原始引文仍保留于数据作为审校证据。书中解释明确归于本书观点，不覆盖馆方记录。
- `objects` 区分文物、器物类别、文献作品、遗址、建筑及当代设计。所有条目均可搜索；没有明确年代的条目不编造时间轴坐标。
- 只有依据明确的同一器物才使用 `existingId` 关联馆藏档案。例如天星观虎座鸟架鼓、九连墩虎座鸟架鼓与泛称“虎座鸟架鼓”分别保留。
- 索引原始交叉关系可能只表示同段提及，不能当作纹样实证。讲解页的延伸阅读只挑选讲解实际提到的对象／主题；配图另外人工选取。
- 书中配图保留原图性质和页码；楚帛书彩图是摹本，不能作为原件色彩依据。未能确认身份或图注不匹配的图片不强行指派。

## 更新和检查

本地核读记录位于仓库外 `../research/jingchu-book/`，含三个逐页清单、提取的文字和图像核对记录。修改核读清单或馆藏目录后运行：

```sh
python3 scripts/build-book-index.py ../research/jingchu-book
node scripts/check-book.mjs
```

构建时逐条将引文与对应 PDF 页文字层比较；图内手工转录单独计数。`docs/book-verification.json` 保存最终对象、主题、引文数量及校验结果。CI 检查页码覆盖、跨页引文拼接、引用关系、图像文件、目录身份、指定新增器物及取消功能未重新出现。

本索引依据这一本书及单独标出的馆方资料，保留其论述边界；“已核读”表示完成该页内容及配图检查，不代表独立验证了书内每项历史判断。

## 综合讲解

`book-motif-summaries.json` 与 `book-object-summaries.json` 分别为 236 条主题和 391 条对象提供语义整理，不通过首段截取生成。每条记录包含讲解正文、支撑原段 `passageIds`；主题可附最多两条 `figureObjectIds`。仅见于图注、文献题名或顺带提及的记录保持简短，并说明来源范围。文物、器类、文献及当代设计的身份区分保持不变。

两个文件使用源 PDF SHA-256 绑定版本；每条支持原段必须属于该条索引。编钟等已关联器物档案同样使用此讲解层。维护索引后须核对讲解及页码再发布，不能静默显示不匹配版本。
