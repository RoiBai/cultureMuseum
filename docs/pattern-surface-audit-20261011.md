# 器表纹饰与拓影核查 · 2026-10-11

本次检查全部 386 件器物，包含 257 件新增馆藏。纹样字段只表示器表的彩绘、刻划、浮雕或镂空装饰，不以整件器物的动物、人物轮廓替代纹样。动物陶塑、鸟首形流、龙形玉佩、鹿角立鹤等整体形制仍保留在器物形制观察中，但不据此参加纹样比较或提供造型拓影。

共调整 84 条器物的纹样分类，其中还纠正了把“盘龙城”识别为龙纹、把鸟篆铭文识别为禽鸟纹、把普通云纹混称云雷纹及重复凤鸟/禽鸟标签的问题。竹简、木牍的正文也不作为装饰纹样。

工坊提供 **72 张**可以使用的器表纹饰拓影。其中 **39 张来自 35 件新增馆藏**，其余 33 张保留原有器物的有效纹饰局部。新增来源中共有 58 件具有可确认的纹饰记录；有文字依据但当前照片背面未展示、纹饰磨损、反光或像素不足的，不强行提取。全清单保留 158 条有依据的纹饰记录，86 条暂不提供设计素材；它们不会出现在工坊素材列表中。

工坊新增材质筛选，以及“新增馆藏纹样 / 原有馆藏纹样”筛选。默认示例换为彩绘漆豕口形双耳长盒盖的器表变形凤鸟纹，避免继续使用凤鸟悬鼓的整体外轮廓。原有已保存设计若包含被撤下的伪纹样，载入时移除对应素材，不把另一张图偷偷替换进去。

## 提取与复核

每一个可用局部保留器物编号、馆方来源、照片路径、归一化裁切坐标与照片 SHA-256。新增素材由现有馆方照片中的真实线条提取：彩绘器优先分离颜料，青花分离青花色区，刻线/浮雕采用去噪后的边缘提取。排除器物的外轮廓与裁切边界；只做显示边缘的平滑，不补绘照片里缺失的纹样。它们是照片数字拓影，不是文物的实物拓片，也不声称提升原照片的真实分辨率。

曾尝试提取但未通过可辨认性检查的局部，包括嵌地几何云纹铜敦、菱形纹铜镜、错银凤纹铜樽、部分漆器破损器面及斑豹盒盖等。完整逐件记录与未制作理由见 [pattern-surface-audit-20261011.json](pattern-surface-audit-20261011.json)。

## 复现与检查

在具有 Pillow、NumPy、OpenCV 的 Python 环境运行：

```sh
python3 scripts/audit-patterns-20261011.py

node scripts/check-pattern-evidence.mjs
node scripts/check-studies.mjs
node scripts/check-map-workshop.mjs

```

提取脚本不处理 `form` 或仅用于定位的 `context`。原有有依据、可辨认的细节资产被保留，不批量覆盖。旧提取实现保存在 `scripts/prepare-rubbings-legacy.py` 仅供追溯，不应作为新工坊的数据生成入口。
