# 三维图谱、点云与镇馆之宝

## 入口

- `index.html?view=xyz`：147 件记录，X 为等距时代分段、Y 为城市类别、Z 为照片前景主导有彩色的 HSV 色相。点击器物进入档案；左侧时代可聚焦，筛选保留原位并淡化不匹配项。灰阶单列。不是实年间距或地理距离。
- `index.html?view=particles`：全档案参与筛选，可随机召唤且尽量避免连续重复；也可选择具体器物。30,000 个粒子从星尘变为器物。`&object=drum` 可直接召唤指定物件。
- 镇馆之宝实验互动暂时隐藏（2026-10-02，用户要求）。主页仅保留直达 `chimes/` 的“编钟音乐”入口；普通器物档案不再展示其他珍藏互动入口。旧 `treasures.html` 总览链接转到编钟，非编钟旧详情链接返回普通器物档案，郧县人返回主图谱。实现与素材保留，待后续重做。

## 点云依据

`pointcloud-volume.js` 根据器形分为八类完整三维表面：回转器（50 件）、分部雕塑（51）、剑（3）、薄片器（24）、织物（3）、盒案（9）、三足器（5）、凤架鼓（2）。圆器沿整周采样；鼎包含器腹、内壁、空间三足与双耳；鼓保留照片中开敞的鼓框并增加鼓腔与支架；剑有菱形剑脊和立体剑柄。正面、侧面、俯视均可直接切换，表面法线参与实时照明和深度遮挡。照片色彩投影到曲面，背面与厚度是结构推演，不是摄影测量。玉佩、剑等原本较薄的器物保留其形制。

147 件照片均已实际生成并验证有限坐标；合成轮廓测试另外约束圆器、器腹和盒体的深宽比，避免退化成前后两张薄片。编钟有模型时跳过照片推演。

编钟复用 `chimes/assets` 用户提供的 Tripo 照片生成模型（不是文物扫描），按三角形面积随机采样，继承纹理。点云不把可互动区域数量误称为原器钟数。其他 Tripo 模型接入 `data/pointcloud-models.json`，优先于单图推算。脚本 `scripts/import-pointcloud-model.mjs` 验证自包含 GLB 后接入，不会自动覆盖已有文件。
