# 颜色图谱：暂时只展示三维

颜色图谱默认进入三维。原有 `?view=hue` 链接和旧的二维颜色浏览会话会转到三维；“二维图谱”主导航仍是器物年代图，不受影响。

二维颜色排列的 `colour-hue.js`、`colour-hue.css`、`#atlas-hue` 面板和切换按钮均保留。恢复时将 `dist/colour-view-config.js` 中 `COLOUR_HUE_ENABLED` 改为 `true`，并更新 `app.js` 对配置模块的版本参数。两枚维度按钮会重新出现，三维仍是默认入口。

三维颜色圆与器物照片默认一轮 30 秒，两段交替各约 6 秒；颜色圆以 12 秒周期作 3% 的尺度呼吸，不使用光环。“交替节奏”滑块支持 12—60 秒 / 轮，当前秒数实时显示，大小呼吸同步按比例调整。拖动只改变时间推进速度，不重置当前相位，也不会解除暂停。偏好保存在 localStorage 的 `jingchu-colour-cycle-seconds`，刷新后继续使用。

两个透明图层均不写入深度缓冲，防止照片被渐隐色球遮挡。暂停会冻结当前状态；减少动态效果默认静止。从器物档案返回时保留相机、速度及暂停位置。会话记录保存规范化的周期、呼吸位置和逐件混合比例；照片尚未加载时先显示完整色圆，加载后平滑恢复。旧会话缺失新字段时使用已保存的速度偏好或默认值；存储中的时间和混合比例均经范围校验。

必要验证：`node scripts/check-colour-breathing.mjs` 检查慢速交替、调速时相位连续、暂停 / 减少动态效果、速度偏好与会话兼容性，以及异步照片恢复。
