# 2026-10-11 颜色图谱本地改版

本轮仅在本地修改，未提交、未推送 GitHub。

## 三维颜色图谱

- 默认 `ColourCluster` 仍以整组照片配色的 OKLab 占比中心定位，每一个节点对应一件器物。
- 去掉主点光晕、背景雾团和卫星光点。器物位置在主色色球和透明前景照片之间每 12 秒交替；每次交叉淡变持续 1.2 秒，各节点相位错开。
- 提供暂停按钮；`prefers-reduced-motion` 初始为静止。悬停时保持器物照片，方便查看和点击。
- 照片上传 GPU 前压缩到最长边 160 像素，并发加载最多 4 张。原始文件不被修改。
- 原设计原样保留在 `dist/colour-cluster-legacy.js`，由首页路由 `index.html?view=colour&colourStyle=legacy` 加载，不出现在导航。

## 二维颜色图谱

入口为 `index.html?view=hue`，模块导出 `ColourHue`。构造参数、筛选、时代跳转、聚焦、显示/隐藏、导航状态接口与其他图谱相同。

- 主色按照片色卡占比排序后的第一色确定。
- 小圆点严格按 HSV 色相横向、明度纵向定位，无彩色分置右侧。器物图片为避免重叠分配到附近空格，与真实色点用线连接，不能把避让图的位置误当成色值。
- 默认图片保留约 34 像素的屏幕尺寸。数量较大时延长画板，支持拖动与缩放，“全景”按钮缩到完整画板。
- 筛选后匹配器物重新疏排；未匹配只保留淡色锚点，仍在同一色值坐标系中。
- 悬停或键盘聚焦时，背景按照该器物照片配色占比划分色条，展示 HEX、占比和器物小图；离开恢复黑底。点击器物打开档案。
- 用 700 件单红色和 700 件无彩色的极端样本检查不丢项、不复用格位；另检查三原色锚点确实在 0° / 120° / 240°。

## 传统色名与来源

古籍释色由 13 条扩至 37 条，保留原 161 条现代色卡最近色匹配数据，照片原色不被参考色替换。检索支持古名、古籍、原文和解释。

用户提供的 [华夏色谱](https://yue-77.github.io/chinese-colors-atlas/index.html) 作为线索，不直接将其中历史叙述、诗句归属或现代 HEX 视为古籍事实。新增条目按如下正文核对：

- [《说文解字》卷五](https://zh.wikisource.org/zh-hant/說文解字/05)：丹、彤、青。
- [卷七](https://zh.wikisource.org/zh-hant/說文解字/07)：白、皎、皑。
- [卷十](https://zh.wikisource.org/zh-hant/說文解字/10)：黑、赤、赭、黯、黝。
- [卷十三](https://zh.wikisource.org/zh-hant/說文解字/13)：缃、绯、纁、缁、缙、綪、縓、緅、絑及已有织物色词。
- [《楚辞·大招》](https://zh.wikisource.org/zh-hant/楚辭/大招)：黛。
- [《宋史》卷四百七十八](https://zh.wikisource.org/zh-hant/宋史/卷478)：天水碧。
- [《红楼梦》（程甲本）第三十五回](https://zh.wikisource.org/zh-hant/紅樓夢（程甲本）/三十五)：松花、桃红、葱绿、柳黄、石青在络子配色中的使用。

修正旧库“黑”引用“缁”、“白”引用“缥”的错配。参考站已经提供的部分颜色可显示其现代示意圆点，并明确标注示意值来源；不添加自定“古代标准 HEX”。

## 视觉

颜色目录、配色工作台改为黑色底与可读的浅朱红字。工作台画布默认墨色纸改为中性黑 `#161215`；展示底板为 `#09090b`。照片颜色和用户选择的配色色值保持不变。
