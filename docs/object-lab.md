# 器物实验室

器物实验室统一收纳编钟音乐、虎座鸟架鼓、曾侯乙尊盘、鸳鸯形漆盒、猪形酒具盒和二十八宿图衣箱。六项体验共用导航，各自保留现有声音与三维实现；之前隐藏的其他珍藏实验不恢复。

## 入口与操作

- `object-lab.html`：首页唯一的器物实验室入口，默认打开虎座鸟架鼓。页内导航按编钟、鼓、尊盘排列；手机横向浏览六个完整器物名称。
- `chimes/`（兼容 `chimes/index.html`）：曾侯乙编钟音乐。保留环看、敲击、曲目播放及编钟档案直达链接，页头和六项导航与器物实验室一致。
- `object-lab.html?object=drum`：虎座鸟架鼓。点鼓面中央、边缘或 A / S / D 敲击；音色和振动随位置变化。录制最长 16 秒、32 个鼓点，保留击打位置、力度、间隔并回放，不采集麦克风。虎座、凤架、悬鼓可点击观察；关闭鼓面示意可查看原生成模型。
- `object-lab.html?object=hb-6911`：曾侯乙尊盘。拖动内尊或使用滑条/按钮，依次提尊、添冰、归位、斟酒；透视显示冰在盘内、酒在尊内，配合冷却示意。至少三块冰是互动任务规则，并非历史使用数量。
- 两件均可旋转、缩放、切正面/俯视；键盘方向键旋转、Home 回到全貌。升降把手支持方向键与 Enter。返回时间轴沿用原图谱状态。
- 首页只保留一个器物实验室入口；三件器物档案的入口仍直达各自体验。旧两件实验链接重定向至对应新页，其余旧珍藏实验仍隐藏。
- 六项导航使用同窗口的普通页面链接，不嵌入 iframe，不预载另一项体验的入口模块或模型。共用 `lab-navigation.css`；桌面页头与导航合计 138px，手机合计 126px，保持原有鼓与尊盘展台布局。

## 知识依据与表达边界

1. [湖北省博物馆：虎座鸟架鼓](https://hbsbwg.cjyun.org/zgzb/p/6913.html)：2002 年枣阳九连墩二号墓出土。两只背向卧虎承托凤鸟，鼓悬于凤冠之间，两只小兽协助托鼓。页面随点击呈现结构关系。
2. [湖北省博物馆在 Google Arts & Culture 的尊盘说明](https://artsandculture.google.com/asset/bronze-zun-and-pan-of-zeng-hou-yi-pan/vgGnLLw-nwjnLA?hl=zh-cn)明确记载铜尊装酒、铜盘盛冰；[馆方器物档案](https://www.hbww.org.cn/zgzb/p/6911.html)用于器物身份和尊、盘组合核对。
3. 原 GLB 是照片生成的融合表面。运行时按空间区域分出尊与盘，补充底面、内腔和鼓面，均为教学示意，不代表实测壁厚、真实容量或考古装配序列。模型细小镂空与纹饰可能简化，不据此讲解失蜡法制作细节。
4. 鼓声由 Web Audio 合成，不是原器录音或古代音色复原。冰块、酒液颜色、冷却速度均为视觉说明，不代表历史温度或时间数据。

## 模型与加载

`models/dragon-ring.glb`（9.68 MiB / 200,000 面）、`models/bronze-vessel.glb`（10.21 MiB / 199,985 面）保留 2048² 色彩、法线和金属/粗糙度贴图；按页加载，不预取另一模型。源文件未修改。点云模式也使用这两个网格进行表面采样。

可复现处理步骤见 `scripts/README-tripo-models.md`；文件哈希、几何信息和优化量见 `dist/models/optimization-report.json`。Khronos glTF Validator 两件均为零错误；原文件已有的自动生成切线空间警告保留，由 Three.js 处理法线贴图。

## 验证

`npm run check` 包含尊盘步骤门限、重置、冷却暂停、录制边界、音频回放替换及异步取消；模型检查覆盖身份关联、GLB 自包含、哈希、体积、加载预算和语法。浏览器另检查实际加载、直接击鼓、录制/回放、升降/放冰/斟酒/透视、返回与手机布局。页面隐藏时停止声音；BFCache 恢复场景；取消拖拽时恢复旋转。

新增三件漆器的操作、来源与验证详见 [颜色与漆器互动](colour-and-collection-labs.md)。
